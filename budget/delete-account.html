예산가계부

계정 삭제 및 데이터 파기 안내

예산가계부 서비스 탈퇴 및 데이터 삭제 방법에 대한 안내입니다.

1. 앱 내에서 직접 계정 삭제하기 (권장)

예산가계부 앱을 이용 중이시라면, 앱 내 설정 메뉴를 통해 간편하게 계정을 삭제하고 모든 데이터를 즉시 영구 삭제할 수 있습니다.

  1. 예산가계부 앱 실행
  2. 우측 상단 설정 (톱니바퀴 아이콘) 또는 프로필 메뉴 이동
  3. '계정 관리' 또는 '회원 탈퇴' 선택
  4. 안내 사항 확인 후 '계정 영구 삭제' 버튼 터치

※ 계정이 삭제되면 복구가 불가능하며, 클라우드에 저장된 모든 가계부 데이터와 내역이 즉시 파기됩니다.

2. 웹에서 계정 삭제(탈퇴) 요청하기

만약 앱을 삭제했거나 앱 내 접근이 불가능한 경우, 아래의 고객지원 채널을 통해 계정 삭제를 요청하실 수 있습니다.

  • 요청 방법: 문의하기 페이지로 이동하여 가입하신 이메일 주소와 함께 "계정 삭제 요청" 메세지를 남겨주세요.
  • 처리 기간: 요청 접수 후 본인 확인 절차를 거쳐 영업일 기준 3일 이내에 계정 및 관련 데이터를 완전히 삭제합니다.

3. 삭제되는 데이터 항목

계정 삭제 시 회사의 서버(Firebase Firestore)에 저장된 아래의 모든 정보가 지체 없이 파기됩니다.

  • 사용자 계정 정보 (이메일, 고유 식별자 UID)
  • 카테고리별 예산 설정 데이터
  • 수입 및 지출 내역 전체
  • 헌금, 부채, 비상금 관련 트랜잭션 기록
